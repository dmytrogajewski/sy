# JOURNEY-20261017-0030: Install base sy with only the power feature

## Actor & Goal

- Actor: Fedora user installing selected sy features.
- Goal: Install the small `sy` command, add the power menu, and use `sy power` without the desktop/AI bundle.
- Hardest constraint: The base RPM must not depend on GUI or inference libraries; the power feature must work without `sy-desktop`.

## Happy Path

1. Install the matching `sy` RPM. The launcher in `crates/sy-launcher/src/main.rs` prints package-aware help through `sy --help`.
2. Install `sy-system-power`. The launcher delegates `sy power reboot --dry-run --json` to the standalone command in `crates/sy-power/src/main.rs`; stdout shows the exact action and no session change occurs.
3. Run `sy power`, choose an action in fuzzel, and confirm a session-ending choice. `crates/sy-power/src/lib.rs` executes the selected `systemctl`, `niri`, or `swaylock` action.

## Edge Cases

- **Power RPM absent**: `sy power` exits 69 and names `sy-system-power` on stderr.
- **Desktop RPM absent**: a desktop command exits 69 and names `sy-desktop` on stderr; `sy --help` still works.
- **Menu dismissed or confirmation cancelled**: no session action runs.
- **Action command fails**: power reports the command and exit status on stderr and exits nonzero.
