# JOURNEY-20261018-2339: Drag side-panel items into applications

## Actor & Goal

- Actor: Desktop user with clipboard history and stack items in the right panel.
- Goal: Drag a screenshot from clipboard history into a terminal to insert its file path.
- Hardest constraint: Start a real Wayland drag using the panel's connection, origin surface and active pointer-grab serial.

## Happy Path

1. Take a screenshot to the clipboard; `stack::clip::top` lists the history entry (`crates/sy-desktop-shell/src/stack/clip.rs:34`).
2. Press the panel entry and move at least 6 logical pixels. Decode the original bytes to a private, stable runtime file and offer `text/uri-list` over Wayland.
3. Release over a terminal. The terminal inserts the screenshot path; the original screenshot remains available for subsequent commands.
4. Drag a text entry into an editor or terminal to insert its text; drag a saved stack file to offer its existing path (`crates/sy-desktop-shell/src/stack/state.rs:187`).
5. Click without dragging to keep the existing copy behavior; right-click to keep the action menu (`crates/sy-desktop-shell/src/stack/bar/app.rs:425`).

## Edge Cases

- **Expired clipboard entry / failed decode**: No empty file or empty drag; report the failure with a desktop notification and tracing.
- **Cancellation or rejected drop**: Keep clipboard history and source files; next click/drag works. Only copy is advertised.
- **Spaces, Unicode and URI metacharacters**: Percent-encode paths in URI lists, preserving every path byte.
- **Refresh during a gesture**: Retain the selected payload independently of reordered history; hover previews do not open during a press/drag.
- **Missing Wayland data-device support**: Keep click/menu behavior and report unavailable drag support in tracing.

## Manual Verification

Run `cargo run -p sy-desktop-shell -- stack bar` in a Niri session without another panel instance. Capture a screenshot into cliphist, then drag its panel entry into a terminal. Inspect the inserted path with `file` and open it to confirm full resolution. Repeat with spaces/Unicode in a saved file path and with a text clip. Click a clip to copy; right-click for actions. Cancel a drag with Escape and repeat. Hold a slot beyond the hover delay: no popup should interrupt the drag. Leave the dropped path in the terminal, wait for a history refresh, then verify the file is still readable.

## Out of Scope

- Inbound drops onto the panel, file-manager drag support, and emulating paste through terminal keystrokes are separate workflows.
- The receiving terminal chooses how to quote/insert file URIs; this feature supplies the standard Wayland file offer.
