- **B.** BUG-20260712-1200 — `call_active` was edge-triggered, not


## Known limitation: NPU lever blocked on amdxdna permission

`xrt-smi` (in `/opt/xilinx/xrt/bin`) advertises `--pmode`, but the
runtime probe fails: `DRM_IOCTL_AMDXDNA_SET_STATE err=-13 Permission
denied` against the amdxdna driver, so the NPU lever is a clean
no-op per P1-1 (INFO once at startup, no WARN spam). The `677cd8d`
probe cache surfaces the stderr at debug level so a follow-up can
decide whether this is an XDNA driver permission gap (udev/group on
the accel node) or a missing device argument. "Every actuator writes
cleanly" is currently met in the no-op sense for NPU.
