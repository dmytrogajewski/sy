# BUG-20260827-0511: Claude route exceeded engine context

## Summary

The real headless Claude client sent a 40,750-token request, while the declarative llama.cpp profile exposed only a 32,768-token context.

## Reproduction

`sy spark dgx-spark launch claude --model qwen3.8:27b` reached the configured Anthropic route, then llama.cpp rejected the request because prompt tokens exceeded the active context.

## Fix

The generic Spark llama.cpp profile now configures a 65,536-token context. This is engine policy in TOML and applies uniformly to compatible catalog models.

## Traceability

- Test: `spark::engine::tests::llama_cpp_profile_supports_real_claude_context`
