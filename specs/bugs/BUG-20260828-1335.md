# BUG-20260828-1335: Adaptive reasoning effort is dropped or overridden

## Summary

The compatibility gateway either omitted client reasoning effort or combined it
with a contradictory fixed profile budget. The latter made Claude's `low`
effort behave like the profile's 8,192-token default. The Responses rewrite
also accepted Codex's `reasoning.effort` without forwarding it.

## Reproduction

- Method: unit test plus real DGX Spark agent run
- Test: `spark::gateway::tests::anthropic_effort_is_mapped_by_the_engine_profile`
- Command: `sy spark dgx-spark launch claude --model qwen3.8:flash-next -- --effort low --print ...`
- Evidence: after effort forwarding was added, a fresh Claude Tetris run still
  generated roughly 28,000 tokens before its first response ended and left the
  workspace empty. A minimized streaming probe proved tool streaming worked.
  The rewritten request contained both `reasoning_effort=low` and the fixed
  `thinking_token_budget=8192`; an action-constrained run then produced files,
  confirming the failure was reasoning-control precedence rather than tools.

## Expected

Client-requested effort reaches the engine using the engine profile's
declarative effort mapping and exclusively controls adaptive reasoning. An
explicit client token budget wins when supplied. The profile budget remains a
default only when the client supplies neither control.

## Actual

Anthropic effort was initially dropped. After forwarding was added, sampling
defaults injected `thinking_token_budget` even when adaptive effort was
present. The Responses rewrite accepted its `reasoning` object but ignored
`reasoning.effort` entirely.

## Root Cause

The generic sampling-default pass treated a fixed token budget as independent
of adaptive effort, although both control the same upstream reasoning budget.
Protocol validation and rewrite coverage also diverged: accepted Responses
fields were not necessarily represented in the OpenAI-compatible request.

## Fix

Forward Anthropic and Responses effort as OpenAI `reasoning_effort` and let
each declarative engine profile translate source effort names. When adaptive
effort is present without an explicit client budget, omit the profile's fixed
budget so the model can apply its effort-specific policy. Keep the configured
8,192-token budget for clients that send no reasoning control. Reasoning stays
enabled in every case.

- Fixed in: `src/spark/gateway.rs`, `src/spark/engine.rs`, `configs/sy/spark/engines/vllm-qwen38-mmap.toml`, `tests/spark_anthropic_e2e.rs`
