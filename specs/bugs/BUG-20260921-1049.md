# BUG-20260921-1049: Release build omits pinned Rust components

## Reproduction

Sparkplane release run 35573847722 passes all contract tests, then both build
jobs fail before compiling. The first Cargo command implicitly installs the
components in `rust-toolchain.toml` and rustup reports a `bin/cargo-fmt` conflict.
The toolchain setup installed only the minimal profile and target; unlike the
passing contract job, it omitted explicit `clippy,rustfmt` components.

## Expected and fix

All release jobs install the complete pinned toolchain before invoking Cargo.
Add the missing components to the build setup and retain the pinned toolchain.
The new regression test fails against the original build setup and passes when
both repository-declared components are installed. The failed v0.1.1 tag remains
immutable; the corrected release is v0.1.2. Production is unchanged.
