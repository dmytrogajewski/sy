# BUG-20260827-0542: Muse resolver unavailable from Spark region

## Summary

Hugging Face returned HTTP 403 for the publisher Muse artifact resolver from `dgx-spark` with `This model is not available in your region`, while metadata APIs remained healthy.

## Reproduction

The pinned publisher download never reached transfer. A bounded resolver probe on the Spark reproduced the regional 403 for both selected files without changing the protected platform.

## Fix

The declarative catalog now pins `lactroiii/Muse-Glimmer-30B-GGUF@c8e212a87fbc137e44463663fb7550ae92079849`, a public mirror whose selected primary and projector have the exact publisher byte counts and SHA-256 values. No proxy, compatibility path, or model-specific Rust was added.

## Traceability

- Test: `spark::model_catalog::tests::recommended_catalog_resolves_exact_immutable_artifacts`
- Real artifact SHA-256 values: `ac7023d6...a6c38`, `f48b4523...00c6`
