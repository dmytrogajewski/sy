# BUG-20261018-0000: Test run rewrites tracked Markdown golden

## Summary

`make test` modified `tests/fixtures/sy-plugin-md-readme.golden.png` while running the keyring smoke test.

## Reproduction

- Run `make test` with `strace` installed.
- `git status --short` shows the tracked README golden changed after the run.
- The smoke test executes `regen_goldens`, which writes both fixture files to the checkout.

## Expected

Tests leave tracked files unchanged and write temporary outputs outside the checkout.

## Actual

The strace child invoked the fixture regeneration example without redirecting its output.

## Root Cause

The example had only hardcoded fixture destinations, and the smoke test used it for a read-only behavior check.

## Fix

Allow `SY_GOLDEN_OUTPUT_DIR` to select an output directory and set it to a temporary directory in the smoke test. The normal manual regeneration command still writes the tracked fixtures.

## Traceability

- Evidence: tracked golden mtime changed during `make test` on the Fedora 44 host.
- Fixed in: `crates/sy-plugin-md/examples/regen_goldens.rs` and `crates/sy-plugin-md/tests/no_chrome_no_keyring.rs`.
- Verification: target test passed and the golden's SHA-256 remained unchanged during that run; rerun `make test`.
