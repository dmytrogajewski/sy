# BUG-20260829-0121 — Engine JIT cache placed on non-executable tmpfs

## Report

The real DGX Spark SGLang qualification loaded the complete NVFP4 model and MTP draft, then failed while loading generated kernel shared objects through two independent cache paths:

```text
failed to map segment from shared object
/tmp/.cache/sglang/jit/.../sgl_kernel_jit_grouped_gemma_rmsnorm_2560_true_bf16_t.so
/tmp/tmpdst5nj75/exported.so
```

## Root cause

Managed engines receive a writable `/tmp` tmpfs with `noexec`, as required by the container isolation policy. SGLang's kernel compiler does not follow `XDG_CACHE_HOME`; without its own environment setting it writes executable JIT artifacts below `~/.cache/sglang/jit`. TileLang also publishes compiled modules through Python's generic temporary-directory API, which is controlled by `TMPDIR` rather than either SGLang cache variable. The engine deliberately sets `HOME=/tmp`, so both generated shared objects landed on the non-executable mount.

## Contract

Engine files declare every cache environment variable whose contents must be executable. The generic engine parser rejects declarations that are missing from `environment` or resolve outside the isolated per-instance `/compile-cache` mount. The mount root itself is valid for generic temporary-directory APIs because it is already content-addressed by engine execution identity, model, profile, artifacts, and instance. SGLang declares `SGLANG_CACHE_DIR`, `SGLANG_JIT_CACHE_DIR`, and `TMPDIR`; no model or engine identity is encoded in Rust.

## Verification

- The parser test first reproduced acceptance of an executable cache below `/tmp`.
- The same test now rejects that configuration.
- A second parser test first reproduced rejection of the isolated cache mount as a generic executable temporary directory, then proved it is accepted without allowing any path outside the mount.
- Every shipped engine declaration parses through the generic catalog loader.
- The first real-device retry proved the SGLang-specific JIT cache moved under `/compile-cache`, then reproduced TileLang's independent temporary-directory failure.
- The corrected signed release is verified on `dgx-spark` through the same managed lifecycle and protocol probes.
