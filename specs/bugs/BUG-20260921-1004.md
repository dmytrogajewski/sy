# BUG-20260921-1004: Historical stopped instances block appliance migration

## Summary

The signed appliance dry-run compares stopped historical instances against the
current engine policy, rejecting legitimate history from earlier deployments.

## Reproduction

- Method: live signed read-only dry-run, then hermetic regression.
- Command: `sparkplane bootstrap migrate-appliance --bundle <verified-bundle> --transition <signed-transition> --transition-signature <signature> --dry-run --json`.
- Evidence: `legacy engine fingerprint differs from running instance` even
  though the only running instance matches the installed policy exactly.
- Stopped instances retain fingerprints and context settings from older engine
  versions. They own no running containers and must remain stopped.

## Expected

Preserve stopped historical instance identities and settings without treating
them as engines to restart. Require exact policy, context, model, and container
agreement for every running instance. Preserve all audit/operation history.

## Actual

Preflight checks current engine fingerprints and profiles before checking
desired state; database conversion repeats the profile/context requirement and
rewrites historical engine fingerprints as though they were live deployments.

## Root Cause

Active deployment invariants were applied to all persistent instance rows.

## Fix

Keep structural/model/artifact validation for all rows; restrict current policy,
profile, cache-key and restart checks to running instances. Convert stopped
metadata namespaces while retaining historical engine fingerprints and context.
Preserve suppression/quarantine flags on stopped rows without reactivating them;
running suppressed/quarantined rows remain rejected.

## Traceability

- Regression: Sparkplane `tests/migration_host.rs`.
- Implementation: Sparkplane `src/migration/appliance.rs`, `src/migration.rs`.
- Published in Sparkplane PR #3, merged as `cfcac99f3d1c903086d5a16d196aa635ccda573a`.
- Live signed preflight passes after this fix and the managed-policy correction.
