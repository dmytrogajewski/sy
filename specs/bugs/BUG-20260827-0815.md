# BUG-20260827-0815: Spark catalogs compiled into installer

## Symptom

Production install code embeds model and engine TOML with `include_*`, so
changing operational configuration requires recompiling Rust.

## Contract

The signed release manifest carries separate catalog file hashes. Activation
verifies those files before authoritatively replacing `/etc/sy/spark`; no
compiled catalog, legacy decoder, migration, inference, or merge is allowed.

## Verification

A source regression rejects production catalog includes, installer tests cover
signature/hash rejection and deterministic replacement, and the signed bundle
is redeployed and smoked on `dgx-spark` without model downloads.

The replacement ARM binary is `af074ac33a45ae64e441c99a713a82bff8383527175bb5da29a49ebad240b969`.
Remote and local payload copies match the signed inventory; the authenticated
Muse Responses smoke completed and the protected fingerprint remained
`7e42b88250e762400e91b902cfa1fcda6b4d1cc118eb6b91fd50716b41cf8510`.
