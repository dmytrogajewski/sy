# BUG-20260828-1910 — Qwen3.6 repeats thinking across coding-agent tool turns

## Report

Qwen3.6 does not implement graded reasoning effort. Setting Codex to `medium`
changes the client header but FreeToken probes the checkpoint template, drops
the unsupported value, and uses the same thinking-on template default. Across
tool turns the checkpoint then discards prior thinking unless
`preserve_thinking=true` is supplied, so it repeatedly derives a plan instead
of progressing through the filesystem work.

## Evidence

On the real `dgx-spark`, the `xhigh` Tetris journey reported 208,056 accounted
tokens and created only an incomplete logic file. A clean `medium` replacement
reported 89,001 accounted tokens, emitted a malformed tool call, created only
`js/randomizer.js`, and stopped. FreeToken logged that `medium` was unsupported
by the checkpoint and used the template default; decode remained 54–64 tok/s
without queueing or health errors. This isolates the failure from Spark compute
throughput and disproves the original effort-tuning diagnosis.

The Qwen3.6 model card recommends preserving thinking for agent scenarios to
avoid repeated reasoning and improve KV-cache reuse. That is a per-checkpoint
template default, not a global engine switch.

The same model card distinguishes general thinking from precise coding and
WebDev sampling. The deployed checkpoint default was `temperature=1.0`; the
coding profile requires `temperature=0.6`, `top_p=0.95`, `top_k=20`,
`min_p=0`, `presence_penalty=0`, and `repetition_penalty=1`.

## Acceptance

- An engine profile may declare bounded `chat_template_kwargs` defaults without
  an engine/model branch in Rust.
- The FreeToken Qwen3.6 profile declares `preserve_thinking=true` and no false
  graded-effort claim.
- The profile declares Qwen's precise-coding sampling defaults; an explicit
  client value still wins.
- Profile defaults reach OpenAI Chat, Responses, and Anthropic rewrites, merge
  with protocol-owned thinking controls, and never disable reasoning.
- A new clean Codex journey completes the Tetris implementation with
  independent tests and a browser smoke check.
