# BUG-20261018-0010: Foot warns for every color setting

## Summary

Opening a terminal prints repeated Foot deprecation warnings.

## Reproduction

- Method: manual parser check on Fedora 44 with Foot 1.27.0.
- Command: `foot -C -c ~/.config/foot/foot.ini`
- Evidence: Foot warned once for each color setting in `[colors]` (21 warnings).

## Expected

Foot accepts the generated configuration without warnings.

## Actual

Foot accepts the configuration but reports that `[colors]` is deprecated.

## Root Cause

The packaged template still uses Foot's deprecated `[colors]` section, and `sy apply` rendered it into the live user configuration.

## Fix

Use `[colors-dark]` in the template and apply the same section name to the live configuration.

## Traceability

- Fixed in: `configs/foot/foot.ini`.
- Verification: `foot -C -c ~/.config/foot/foot.ini` exits successfully with empty stderr after the fix.
