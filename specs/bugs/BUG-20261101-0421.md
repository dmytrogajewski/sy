# BUG-20261101-0421: Fedora RPM build exhausts disk quota during release linking

## Summary

Fedora 45 RPM CI failed while producing release binaries because the runner
exhausted its disk quota during compilation and linking.

## Reproduction

- Run: https://github.com/dmytrogajewski/sy/actions/runs/41258424128
- Failed job: Fedora 45 package build, commit `2af4d98`.
- Evidence: `rustc-LLVM ERROR: IO failure on output stream: Disk quota exceeded`
  followed by failures building file manager, monitoring, and desktop binaries.
- The compiler command included `-Cdebuginfo=2` and `-Cstrip=none`, overriding
  Cargo's stripped release profile. Fedora 43 and 44 passed in the same matrix.
- The object-file regression failed under the original RPM defaults because
  `readelf` found `.debug_info` in a compiled Rust fixture.

## Expected

Release builds omit debug data that the RPM never distributes and preserve
the existing optimization and hardening settings.

## Actual

The spec disables debug packages and strips shipped binaries, but RPM's
compiler flags still generate full DWARF data throughout the build. That data
increases intermediate object sizes and disk demand during release linking.

## Root Cause

`debug_package` controls debug RPM generation separately from the
`rustflags_debuginfo` macro used by Fedora's `build_rustflags`. Disabling debug
packages alone leaves the default debug-information level at two.

## Fix

Set `rustflags_debuginfo` to zero in `packaging/sy.spec`. Keep Fedora's other
compiler flags and all package checks. Include `tests/rpm_build_flags.py` in
the source archive and run it during the RPM check phase. The test compiles a
retained Rust function-pointer object with the actual build environment's
flags, confirms the symbol exists, and rejects unused DWARF sections.

## Traceability

- Regression: `tests/rpm_build_flags.py::ReleaseFlags`.
- Configuration: `packaging/sy.spec` and `scripts/build-rpms.sh`.
- Local regression: fails with the original flags and passes after RPM expands
  the repaired spec to `-Cdebuginfo=0`.
- Fedora matrix verification is pending.
