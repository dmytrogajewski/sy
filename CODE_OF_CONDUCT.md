This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The canonical text lives at that URL — read
it before participating. Participation in `sy` (issues, pull
requests, discussions, chat, or any other project space) means you
agree to uphold it.

## Scope

The code of conduct applies to every space the project maintains —
the GitHub repository (issues, pull requests, discussions, review
comments), any future chat or forum the maintainer announces, and
any in-person or virtual event held under the `sy` name. It also
applies when an individual is representing the project in public,
for example by posting from an official account or speaking at an
event as a `sy` contributor.

## Reporting and enforcement contact

Report a violation by email to **<dmytrogajewski@gmail.com>**. This
is the same private channel listed in [`SECURITY.md`](SECURITY.md)
and referenced from [`CONTRIBUTING.md`](CONTRIBUTING.md), so the
maintainer is the single point of contact for both kinds of
incidents.

Include in your report:

- A description of the incident, with links or quotes where the
  conduct is on the public record.
- The space where it happened (issue / PR URL, discussion thread,
  event name).
- Any context that helps assess impact (whether the conduct was
  directed at you, whether it is part of a pattern, whether you
  have already raised it with the other party).
- Whether you want to be named in the response or kept anonymous.

Reports are handled in confidence. The maintainer will acknowledge
receipt within seven days (the same target as [`SECURITY.md`](SECURITY.md))
and follow up with the outcome once the review is complete. Where
practical, the reporter is asked before any public action is taken.

## Enforcement actions

The maintainer will apply the [Contributor Covenant 2.1 community
impact guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
when choosing a response. Possible actions include a private
correction, a public warning, a temporary ban from project spaces,
or a permanent ban — proportionate to the conduct and to any
pattern of prior incidents.

## Conflicts of interest

If the report concerns the maintainer, or if the reporter prefers
an external party, raise the incident directly with the
Contributor Covenant project's
[suggested escalation paths](https://www.contributor-covenant.org/faq/#how-do-i-enforce-the-code-of-conduct).
The maintainer will recuse from any decision in which they are the
subject of the report.
